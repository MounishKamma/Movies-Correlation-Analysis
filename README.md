# Movie Correlation Analysis Project

## Project Overview
A Python-based exploratory data analysis project focused on identifying correlations between movie attributes such as budget, gross revenue, votes, ratings, and other film characteristics.

The project uses Pandas, NumPy, Matplotlib, and Seaborn to clean, analyze, visualize, and interpret movie industry data.
---
## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
---
## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Data Type Inspection
- Correlation Analysis
- Scatter Plot Visualization
- Regression Plot Analysis
- Heatmap Visualization
- Categorical Encoding
---
## Key Insights
- Movie budget showed strong positive correlation with gross revenue
- Higher audience votes were strongly associated with higher gross earnings
- Certain categorical variables showed weaker correlation with revenue
- Correlation heatmaps revealed major relationships between movie features
